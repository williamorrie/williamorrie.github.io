# williamorrie.github.io

Personal data visualization and analysis blog showcasing various mapping and data projects.

## Featured Visualizations

- **[RTC Clusters](rtc_clusters.html)** - Interactive Mapbox visualization of Road Traffic Collision data with clustering
- **[Cat Polygons](cat_polygons.html)** - Leaflet/Folium map showing cat tracking data with polygon overlays
- **[RTC Heatmap](rtc_heatmap.html)** - Heat map visualization of traffic collision data

## Blog Posts

The site includes posts covering:
- Data processing and visualization workflows
- Mapbox and Leaflet mapping techniques
- Working with prescription data
- Tableau visualizations
- Jupyter notebook integration

## Technologies

- Jekyll with Minima theme
- Mapbox GL JS
- Leaflet/Folium
- GeoJSON data formats
- GitHub Pages hosting

## Local Development

View the site locally:
```bash
jekyll serve
```

Or simply open HTML files directly in a browser for standalone visualizations.
